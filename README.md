# 🧠 ThoughtLens

**Understand your thoughts. Recognize patterns. Reflect with clarity.**

ThoughtLens is an ML-powered cognitive distortion awareness and self-reflection web application designed to help users recognize potentially unhelpful thinking patterns in their everyday thoughts.

Users can enter a thought, and ThoughtLens uses a trained machine-learning model to identify possible cognitive thinking patterns such as overgeneralization, mind reading, labeling, magnification, and all-or-nothing thinking.

Instead of simply assigning a label, ThoughtLens provides beginner-friendly explanations and guided reflection questions that encourage users to examine their thoughts from different perspectives.

## ✨ What it does

- 📝 Analyze everyday thoughts
- 🧠 Identify possible cognitive thinking patterns
- 🔍 Show the top 3 model predictions
- 💡 Explain each pattern in simple language
- 💭 Guide users through structured reflection
- 💾 Preserve their current analysis and reflections across page refreshes
- ⚠️ Clearly communicate that the tool is educational and not a medical diagnosis

## 🛠️ Tech Stack

- **Machine Learning:** Python, Scikit-learn, TF-IDF, Linear SVM
- **Backend:** FastAPI
- **Frontend:** React + Vite
- **Model Persistence:** Joblib
- **Development:** Google Colab + Antigravity

## 🎯 Purpose

ThoughtLens is designed as an educational self-reflection tool—not a replacement for mental-health professionals or a diagnostic system.

The goal is to help users pause, recognize possible patterns in their thinking, and reflect before automatically accepting a negative thought as fact.
